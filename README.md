# IRENE DEV PORTFOLIO

A premium cosmic developer portfolio built with Next.js, React, Tailwind CSS, and Framer Motion.

## Features

- Cosmic dark aesthetic with purple, blue, and cyan gradients
- Sticky responsive navigation and mobile menu
- Animated hero with orbiting 3D-style cosmic illustration
- About, skills, project, services, journey, and contact sections
- Reusable data-driven content structure
- Contact form validation ready for future backend/email integration
- Responsive layout for desktop, tablet, and mobile
- SEO metadata and accessibility-friendly markup

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Production build

```bash
npm run build
```

## Deployment

This project is ready to deploy to Vercel with the standard Next.js setup.
